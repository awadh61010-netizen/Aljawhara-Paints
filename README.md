# Aljawhara Paints - دهانات الجوهرة

نسخة أولية لتطبيق Android على التابلت لمعاينة ألوان دهانات الجوهرة.

## الموجود في النسخة الأولى
- واجهة عربية كلاسيكية وهادئة.
- شعار دهانات الجوهرة الأصلي وشعار FFA.
- اختيار صورة منزل من معرض الصور.
- لوحة ألوان قابلة للاختيار.
- معاينة لونية أولية على الصورة.
- GitHub Actions لبناء ملف APK تلقائيًا.

> ملاحظة: تغيير لون الجدران وحدها بالذكاء الاصطناعي/التحديد التلقائي هو المرحلة التالية. النسخة الحالية تجهز التطبيق والواجهة والبناء وتستخدم تلوينًا شفافًا للصورة كمعاينة أولية.

## بناء APK
بعد رفع الملفات إلى GitHub، افتح تبويب Actions وشغل `Build Android APK`.
بعد نجاح العملية ستجد ملف APK داخل Artifacts باسم `Aljawhara-Paints-APK`.
